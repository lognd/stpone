\chapter{Bench self-test summary}\label{app:bench}
\index{bench tests}

\textit{For technicians.} The full procedures are in
\texttt{docs/runbooks/hardware-tests.md} in the source repository. Each test
loads one test image with \texttt{scripts/flash.py --target <name>} and checks
the panel. Record pass/fail and notes for each. The expected values were
worked out from the design and source code and have not yet all been
confirmed on a real machine.
