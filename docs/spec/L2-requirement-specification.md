# L2 -- Requirement specification

Refines `L1-requirements.md` into precise, testable statements. Every
SPEC satisfies one or more REQs and is verified by one or more CTP items
in [`L2-customer-test-plan.md`](L2-customer-test-plan.md). Numbers here
are the contract; lower levels may not loosen them without a decision
record. All numbers are those of the accepted `stp-upgrade` firmware.

## A. Winding

| ID | Specification | satisfies | verified-by |
|---|---|---|---|
| SPEC-001 | Length model: measuring wheel diameter 4.0015 in (DEC-003), circumference `3.14159265 * 4.0015` = 12.571 in (float32); encoder 600 PPR read at 4x = 2400 counts/rev; targets 1080 in (30.0 yd, BTN1) and 3240 in (90.0 yd, BTN2); target pulses = `uint32(L * 2400 / 12.571)` = 206187 and 618562; the stop point of a panel wind is `goal - coast` with `goal = target + margin` (margin 191 pulses = 1.0 in, coast 2291 pulses = 12 in by default, DEC-010); yards shown = `|count| * 12.571 / (2400 * 36)`. | REQ-001, REQ-003 | CTP-001 |
| SPEC-002 | State machine `IDLE -> WINDING` on a BTN1 (30 yd) or BTN2 (90 yd) event, taken only when that latching button is pushed DOWN (the toggle that leaves it up, e.g. resetting the panel after a wind, starts nothing); `WINDING <-> PAUSED` on a BTN3 event (PAUSED: relay OFF, count kept and still read); `WINDING/PAUSED -> IDLE` on a BTN1 or BTN2 event OR (legacy `bump = 0`) `|count| >= goal - coast`; with `bump = 1` (default) the main run ends in `TRIM` (SPEC-007) which returns to IDLE. Entering WINDING: cancel beeps, zero count and `enc_errors`, relay ON, LEDs follow the SPEC-005 bargraph (recomputed every pass, so also while PAUSED). Leaving: relay OFF, LEDs 0b0000, start the beep sequence; the count and `enc_errors` are KEPT (DEC-006) and the controller opens the RESULT bookkeeping (SETTLING until the count has held still for 500 ms, then DONE; cleared by manual ON, `ZERO`, entering debug, the next wind, or 60 s after the stop, which zero the held count), while the machine is a pristine IDLE (relay and manual off). BTN4 is a SOFTWARE manual latch: each BTN4 click (a toggle in either physical direction) flips manual mode, which is OFF at power-up whatever the switch position; there is no arming and the physical level is never followed. Manual works in IDLE and in PAUSED, where the relay follows the manual flag; clicks while WINDING (and the click in the very pass that pauses) are ignored. Manual is cleared on wind start, on resume, on stop, and on entering or leaving debug. The stop rule (BTN1/BTN2 toggle or `|count| >= goal - coast`) is evaluated first on every pass, so manual can never overrun the target. The relay is also dropped by the encoder ISR itself at `enc_stop_at` (the controller's effective target, `goal - coast`, or the bump stop of SPEC-007) without waiting for the main loop (SPEC-006). Each pass consumes at most one pending toggle per button; none are merged or lost. Power-on with any latch down starts and runs nothing; the first BTN4 click then turns manual ON (SPEC-011). Tuning (lengths, coast, wheel, CPR) is reachable only through the host link (SYS-004, DEC-004), never from the panel. | REQ-001, REQ-002 | CTP-001, CTP-002 |
| SPEC-003 | Screens (20x4, fixed columns): idle rows ` -= PAPER WINDER =- `, `MANUAL: motor ON    ` (manual mode on) / `!! | SPEC-004 | Beep sequence: 3 beeps of 300 ms with 150 ms silence between (a failed trim: 3 beeps of 700 ms with 250 ms gaps, repeated every 6 s at most 10 times while the failure is on the display; an operator stop: the single-beep CANCEL pattern), driven from the 1 kHz tick without blocking the loop; `buzz(0)` cancels; a BTN1 or BTN2 press in IDLE cancels before starting. | REQ-004 | CTP-004 |
| SPEC-005 | LEDs: idle pattern 0b0101 (LED1+LED3); while WINDING, TRIM or PAUSED the controller drives the bargraph every pass, segment = `min(|count|,target) * 4 / target`; manual lights LED4 mapped to 0b0000, 0b0001, 0b0011, 0b0111, 0b1111. | REQ-005 | CTP-005 |
| SPEC-006 | Encoder: sampled at 40 kHz; 4x quadrature transition table (index `(prev<<2)|cur`, state `(B<<1)|A`); one direction +1, the other -1, signed 32-bit count (no saturation) read under `cli/sei`; a two-bit jump adds 2 in the last direction and increments `enc_errors`; after each sample the ISR clears the relay pin when `|count| >= enc_stop_at` (`0xFFFFFFFF` = never). Designed for 90 RPM with about 11 samples per state. | REQ-006 | CTP-006 |
| SPEC-007 | Trim (bump) mode, default (`bump = 1`, DEC-010): after the main run cut at `goal - coast` the machine waits for `|count|` to hold still 500 ms, then makes bumps - each armed as `enc_stop_at = |count| + b` and cut by the ISR - first `remaining/2`, then `remaining - over_est` (learned overshoot-after-cut), until `remaining <= 382` pulses (or `b < 8`, or 3 bumps are left of 16), then a final bump with `enc_stop_at = goal` and the relay on until the ISR sees it. PASS (beep, `pass=1`, `DONE`) only when the settled `|count| >= goal >= target`. A bump on for > 1500 ms without a count change for 300 ms is a stall; two stalls, 16 bumps, or 30 s end the wind SHORT (alarm, held `!! UNDER TARGET !!`, `pass=0`); BTN1/BTN2 end it STOPPED (`pass=0`). BTN3 pauses (relay off, ISR disarmed except manual, capped at the goal) and resumes; BTN4 is manual only while paused. Guarantee (conditional on a correct encoder count and wheel parameters): a completed wind has `|count| >= target + margin`. Parameters `coast` (2291), `margin` (191, 0..2000), `bump` (1; 0 = legacy single cut at `goal - coast`, no guarantee). | REQ-001, REQ-007 | CTP-007 |
